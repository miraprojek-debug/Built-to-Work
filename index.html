    Masuk dengan admin / admin123

    Coba demo Dashboard Kehadiran Sekolah (tab baru)Data contoh
  3. 03Manajemen program

    Smart Kontrol Program Pesantren

    Khusus pondok pesantren

    SK dan tupoksi asatidz, program kerja dengan KPI dan milestone, laporan realisasi berfoto, serta dasbor untuk mudir.

    Buka aplikasi Smart Kontrol Program Pesantren (tab baru)
  4. 04Raport pondok

    Aplikasi Raport Pondok 3 Bahasa

    Pondok pesantren

    Pengisian dan cetak raport santri dalam tiga bahasa, dengan akun terpisah untuk admin dan wali kelas.

  5. 05Ujian sekolah

    Aplikasi CBT

    Ujian berbasis komputer

    Bank soal, jadwal dan token ujian, acak soal, pemantauan peserta secara langsung, koreksi, dan analisis nilai.

    Buka aplikasi Aplikasi CBT (tab baru)
  6. 06Media belajar

    Belajar Baca Kitab Gundul

    Untuk santri

    Latihan membaca kitab tanpa harakat kata demi kata, lengkap dengan langkah analisis sampai ketemu harakat akhirnya.

    Buka aplikasi Belajar Baca Kitab Gundul (tab baru)
  7. 07Media belajar

  8. 08Belajar anak

    Belajar Calistung

    Untuk anak usia dini

    Belajar membaca, menulis, dan berhitung untuk anak lewat latihan yang sederhana.

Proses

Dari kertas sampai dipakai setiap hari.

Empat tahap · selalu terbuka

  1. 01tahap 1/4

    Riset

    Memahami alur kerja, membaca dokumen yang ada, dan memetakan kebutuhan sebelum merancang apa pun.

  2. 02tahap 2/4

    Rancang

    Gambaran sistem, rincian fitur, waktu, dan biaya disusun untuk Anda setujui.

  3. 03tahap 3/4

    Bangun

    Dikerjakan bertahap. Anda bisa mencoba hasilnya secara berkala dan memberi masukan.

  4. 04tahap 4/4

    Serahkan

    Sistem dipasang, tim dilatih, dan kami tetap bisa dihubungi setelahnya.
